# レジメンあんちょこ

元の「レジメン副作用チェック」を残し、参照用途に作った独立したアプリです。16レジメンを収載。患者情報・AE入力・Grade自動判定はありません。

## 開く

このフォルダの **`index.html` をダブルクリックしてブラウザで開いてください。** サーバーの構築・起動やインストールは不要です。

HTMLと同じフォルダにある `app.js`、`styles.css`、`data/` なども使います。移動・コピーするときは `regimen-pocket-guide` フォルダごと扱ってください。

## 使い方

元のRegimenAEと同じ、上部でレジメンを選び、カードを縦に読む構成です。基本情報 → 副作用・時期 → 次回投与 → 開始前の順に並びます。配色・書体・カードの基本スタイルは元の `styles.css` をそのままコピーし、参照用項目の補足だけを `guide.css` に加えています。

- **副作用・時期**：「重篤 → 特徴的 → 頻度が高い → その他」の4分類で表示します。「その他」は折りたたみます。副作用名と注意表示を一覧し、「確認ポイント・根拠」を開いて詳細を読みます。出現時期は副作用一覧の下にまとめています。
- **次回投与**：対象薬、該当条件、休薬／変更、回復基準と次回量を並べて確認します。
- **開始前**：適応、禁忌、必要な確認、試験の適格基準、前投薬を参照します。試験条件は「試験参考」と表示します。
- レジメン内検索は折りたたみ内も含めて全セクションを検索し、該当する詳細を開きます。検索中も4分類の順序は変えません。レジメン切替時は検索を解除します。
- 「内容をコピー」は検索結果だけでなく選択レジメン全体をコピーします。「印刷」は全セクションと展開した詳細を対象にします。
- 保存するのはブラウザの同じタブ内でのレジメンとリンク先セクションだけです。既存の `#regimen=venAza&view=next` 形式のリンクは該当セクションへ移動します。画面のタブ切替はありません。

## 医学的内容の範囲

既存15レジメンのAE一覧は元アプリの2026-09-24点検版を移行しています。原著・構成薬レビューと未確認資料の状態は [以前の監査記録](docs/AE_AUDIT_2026-09-24.md) を継承しています。元の `dayHints` は日付ごとの観察メモなので、典型的なAE発症日として表示していません。

現在の時期情報は36件、次回投与に関わる主要条件47件、開始前の確認59件です。発現日が確認できないものは回復期間や観察の目安と明記しています。原著・添付文書の時期情報は、起点・集団・レジメンが異なる数値を混ぜません。

2026-10-07にエプコ＋R²（再発・難治性FL Grade 1–3A）を追加しました。原著全文・補足資料と3構成薬の公式資料から、39項目のAE／安全確認、時期6件、次回投与11件、開始前10件を収載しています。[資料レビュー](docs/EPCO_R2_REVIEW_2026-10-07.md)と[候補ごとの実装照合](docs/EPCO_R2_RECONCILIATION.md)を保存しました。エプコ単剤とは別定義で、国内添付文書と試験プロトコルの条件を区別しています。

休薬・減量は全分岐を網羅した処方支援ではなく、確認できた主要条件の参照用です。レジメンごとの未収載事項を画面下に示しています。各薬剤、初回／再発、寛解前後、国内／海外、静注／皮下注、CTCAE／ASTCTの差を保持しています。試験の適格条件と日常診療での投与可否を同一視しません。数値の自動判定・次回用量の自動算出は行いません。

既存15レジメンの添付文書は原則2026-09-24に取得した資料を読み直したものです。eviQ追補は2026-10-06確認。エプコ＋R²の資料は2026-10-07に取得・確認しました。リンク先は改訂される可能性があります。全レジメンの資料を同日時点で最新版確認したとの意味ではありません。

候補表と出典箇所は [IMPLEMENTATION_CANDIDATES.md](docs/IMPLEMENTATION_CANDIDATES.md)、実装後照合は [VALIDATION.md](docs/VALIDATION.md) を参照してください。

2026-10-07の最終表示はユーザー指定の4分類です。独自の「予防・投与判断・重点観察」分類は廃止しました。元の415項目と臨床本文はデータに保持し、67項目の共通注意書きは画面・コピー時に集約します。そのうちTLSなどを除く62項目を「その他」へまとめています。「その他」を「低頻度」「低リスク」と評価し直したものではありません。[表示候補表](docs/PRESENTATION_REVIEW_2026-10-07.md)に全415項目の配置先を記録しています。

## フォルダと元アプリの分離

このフォルダを丸ごと移動して使えます。必要な論文PDFも `references/` にコピーしてあります。元アプリのJavaScriptを読み込まず、元のセッションキー・PWA名・キャッシュ名も使いません。元の6つのアプリファイルのSHA-256を保存し、変更していないことをテストします。

HTMLを直接開く場合、画面・全レジメンデータ・同梱PDFはローカルから読み込めます。外部の添付文書などへのリンクを開くにはインターネット接続が必要です。

## データ更新と検証

`scripts/build_data.py` に既存レジメンの追補、`scripts/epco_r2.py` にエプコ＋R²のデータがあります。内容を改訂する際は原著・各構成薬資料を確認してから生成してください。コピー元のスナップショットは `data/original-snapshot.json` に保存しています。再生成に必要な元論文は初期作成時の親フォルダ `regimen/` にあり、アプリの利用時には不要です。

表示先は `data/presentation.json` にAE名・元分類・表示分類を明記しています。ビルド時に元データの全項目と照合し、候補表を先に生成します。元データの `danger` / `info` / `warn` は保持し、画面用の `displayTone` で4分類への配置を指定します。

```sh
python3 scripts/build_data.py
node tests/app.test.cjs
```

公開後にデータ／画面を更新する場合は `service-worker.js` の `CACHE_NAME` の版も変更してください。現在は `regimen-pocket-guide-v5` です。

テストは候補データの移行、全セクションの同時表示、検索・レジメン切替・印刷準備・保存範囲、キャッシュ分離を対象にします。DOM代替オブジェクトによる機能テストであり、実ブラウザの表示検証ではありません。
